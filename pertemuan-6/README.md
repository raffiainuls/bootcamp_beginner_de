# Pertemuan 6 — Advanced ETL & Final Project Briefing

## Topik

Advanced ETL & Final Project Briefing

## Subtopik / Materi

- Review materi ETL
- Advanced transformasi: grouping dan aggregation
- Instruksi final project
- Tips penyusunan laporan & PPT

## Output Peserta

- Memahami ruang lingkup final project
- Mampu membuat transformasi lebih kompleks
- Menyusun rancangan proyek simulasi

## Tugas

Final project individu berupa proyek simulasi data pipeline.

Project harus:

1. Membuat pipeline sederhana: Extract dari CSV, Transform dengan Pandas, dan Load ke database SQLite.
2. Menambahkan minimal 2 transformasi, misalnya grouping dan aggregation.
3. Menyusun hasil dalam bentuk dokumen laporan dan PPT.
